# Mini CRM - Sistema de Gestão de Clientes

## Sobre o Projeto
API para gestão de clientes e histórico de interações.

## Tecnologias Utilizadas
- Python 3.11+
- FastAPI (framework web)
- SQLAlchemy (banco de dados)
- SQLite (banco leve para desenvolvimento)

## Como Executar

### Pré-requisitos
- Python 3.11 ou superior
- Git
